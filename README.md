# 📝 To-Do List Web Application

## 📌 Project Description

This project is a simple **To-Do List web application** built using **HTML, CSS, and JavaScript (ES6+)**.
It allows users to manage daily tasks efficiently by adding, completing, deleting, and filtering tasks.

---

## 🎯 Objectives

* To understand and apply **JavaScript ES6 features**
* To practice **DOM manipulation**
* To implement **array methods** like `map()`, `filter()`
* To build a small real-world application without any frameworks

---

## 🚀 Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* ❌ Delete tasks
* 🔍 Filter tasks:

  * All tasks
  * Completed tasks
  * Pending tasks

---

## 🛠️ Technologies Used

* **HTML** – Structure of the webpage
* **CSS** – Styling and layout
* **JavaScript (ES6+)** – Functionality

---

## 💡 Concepts Used

* `let` and `const`
* Arrow functions (`=>`)
* Template literals (`` ` ` ``)
* Spread operator (`...`)
* Array methods:

  * `map()`
  * `filter()`
* DOM Manipulation

---

## 📂 File Structure

```
todo.html
```

---

## ▶️ How to Run

1. Copy the code into a file named `todo.html`
2. Open the file in any web browser
3. Start adding your tasks

---

## 🧪 How to Use

1. Enter a task in the input box
2. Click **Add**
3. Click on a task to mark it as completed
4. Click **X** to delete a task
5. Use filter buttons to view tasks
